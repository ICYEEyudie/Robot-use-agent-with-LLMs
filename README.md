# Robot-Use Agents with LLMs — Survey Website

Static GitHub Pages website analyzing 6 frontier papers on Robot-Use Agents (PEAR, PyRUA-REAL, AgenticRoboRL, uni-robot-agent, CaPtain, ZAP).

## Deploy to GitHub Pages (`github.io`)

1. Create a new repository on GitHub (e.g. `robot-use-agent-survey` or `<username>.github.io`).
2. Upload `index.html`, `assets/`, and `README.md` to the `main` branch root.
3. Open **Settings → Pages → Build and deployment**, set Source to **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live at `https://<username>.github.io/<repo>/` within ~1 minute.

## Adding Part 3 (Our Perspective)
Edit the `<section id="part3">` block in `index.html` (and the `p3_*` keys in the `I18N` object for bilingual support).
